Working across your laptops? Load your latest data file from OneDrive before you start, then Save it back when you finish, so both machines stay in step.

How this works

Enter each child and staff member once. For attendance, tick the days and set a from and to time; the document writes it up for you (for example, Tuesday – Friday 7.45–15.45). Then generate the emergency document, the allergy sheet, or a populated record form per child to send home for parents to check. Each one can be printed, saved as PDF, or downloaded as Word. Set your rates once under Fees & terms and they print on every record form; use Form next to a child to make just theirs.

Everything stays on this device. Use Save data file to keep a backup; Load data file brings it back or moves it to another computer.
